# How do I install an Arcadium game?

## Overview

Arcadium games come as `.adm` files. You can install one directly from the game library.

## Install a game

1. Open Arcadium.
2. Press **I** or select **Install new game**.
3. Choose the game's `.adm` file in the file picker.
4. Select the game in the library and press **ENTER** to play. Press **ESC** to return.

If you want to make your own `.adm` file, see the [game creation guide](creating-games.md).
